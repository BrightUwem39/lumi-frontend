# LUMI Storefront

A responsive premium-fashion storefront built with React, TypeScript, Tailwind
CSS, Framer Motion, Zustand, Swiper, React Router, and React Icons. The catalog
uses a curated subset of DummyJSON data with locally served editorial imagery.

## Development

```bash
npm install
npm run dev
```

Use `npm run build` and `npm run lint` before committing changes.
